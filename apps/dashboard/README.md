# @thaipass/dashboard

Dedicated dashboard application for thaipass (AI Pass proxy gateway).

## Features

- **Health & Connectivity:** Live proxy health checks and OpenAPI reference links.
- **Session & Quota Management:** Client-side encrypted cookie storage and real-time usage balance visualization.
- **Client Configurator:** One-click configurations for Claude Code, Cursor, Cline, AI SDK, OpenAI SDK, and cURL.
- **Model Directory:** Filterable catalog of supported Chat, Vision, Image, Video, and Audio models.
- **Interactive Playground:** Streaming prompt runner measuring TTFT and total latency.

## Getting Started

```bash
bun dev
```

Runs on port 3790.
